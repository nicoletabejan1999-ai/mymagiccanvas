# Chart fonts

The configurator now serves the exact font files supplied in the Google Drive
folder `fonts`.

| # | Font | Local file |
|---|------|------------|
| 1 | Hubiland | `hubiland.otf` |
| 2 | Millerstone Demo | `millerstone.ttf` |
| 3 | Boheme Floral | `boheme-floral.ttf` |
| 4 | Francisco | `francisco.ttf` |
| 5 | Belista | `belista.ttf` |
| 6 | Poppy Shower | `poppy-shower.ttf` |
| 7 | Dancing Script | `dancing-script.ttf` |
| 8 | Savoye LET | `savoye-let.ttf` |

The date continues to use Mukta Mahee ExtraLight from Google Fonts.

The `scale` value for each chart font in `assets/js/config.js` is still the
place to fine-tune how large that face appears in the canvas preview.
